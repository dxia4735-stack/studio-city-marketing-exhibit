# 新濠影汇亲子度假营销研究展 · V3.1

基于地图和公开建筑影像的课堂互动展。正式网站：<https://studio-city-marketing-exhibit.vercel.app>。

## 主要交互

- 地理全景 / 业务拆解、缩放、旋转、俯视、复位与部件选择。
- 17 个竖直观景厢沿同一条不交叉的 8 字外缘运行；橙色 01 厢用于跟踪。
- 「看8字轨迹」进入构造特写；展开「观察橙色01厢完整一周」可播放一周、拖动进度或慢放。速度仅供演示。
- 家庭结构、停留长度与策略选择联动沙盘路线、STP、4P 和建议行动。
- 默认按需渲染；支持暂停、减少动态效果和 WebGL 不可用时的二维地理回退。普通滚轮浏览页面。

## 技术与来源

静态 HTML/CSS/JavaScript，无运行时第三方依赖。原生 WebGL，低面数几何、共享座舱网格和一条弧长参数化轨迹。`reel-path.js` 同时供轨道网格和座舱位置使用；绘制与射线点击使用相同位置与拆解偏移。

详见 [来源与模型边界](REFERENCE.md) 和 [验证记录](VALIDATION.md)。模型不是测绘或施工复原，不提供现场导航；研究建议并非企业现售套餐或已验证销售效果。
